SCM V3 PROFESSIONAL DOCUMENT GENERATOR
=========================================
Upgrade from SCM Enterprise V3 FIX2.

KAK/TOR:
- Structured generator with 5 sections.
- Procurement strategy fields.
- Technical scope, deliverables, specification, acceptance criteria.
- Commercial, schedule, requirements, evaluation and HSE/risk notes.
- Professional A4 document preview and Print -> Save as PDF.

CONTRACT:
- KAK auto-fill for title, budget, scope and payment terms.
- Vendor Master selection.
- Clause Builder: SLA, warranty, penalty, HSE, confidentiality, force majeure,
  termination, tax, dispute and additional clauses.
- Professional contract document preview and Print -> Save as PDF.

No database migration is required for this UI/document upgrade because additional
generator fields are consolidated into existing special_terms/clauses columns.
